The Riven frontend is a [Next.js](https://nextjs.org) web app for browsing and
managing a running Riven instance. It ships in Riven's Docker image, and runs
in the same container as Riven itself.

## How it connects to Riven

The frontend doesn't store any data of its own. Accounts, sessions and media
all live in Riven:

- **Accounts and sessions** are handled by Riven's auth API (`/api/auth`).
- **Library data** comes from Riven's GraphQL API (`/graphql`).

The frontend forwards requests for both of these paths on to Riven over the
container's loopback, so the browser reaches them through the frontend's own
URL, on port `9000`. Neither needs to be told where the other is, and the
frontend shares Riven's API key without it being configured twice.
