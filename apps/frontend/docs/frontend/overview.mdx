The Riven frontend is a [Next.js](https://nextjs.org) web app for browsing and
managing a running Riven instance. It ships as its own Docker image,
separate from Riven itself, and talks to Riven over HTTP.

## How it connects to Riven

The frontend doesn't store any data of its own. Accounts, sessions and media
all live in Riven:

- **Accounts and sessions** are handled by Riven's auth API (`/api/auth`).
- **Library data** comes from Riven's GraphQL API (`/graphql`).

The frontend forwards requests for both of these paths on to Riven, so the
browser can reach them through the frontend's own URL. Because of this, the
frontend and Riven each need to know where the other is:

| Side     | Setting                          | Points at                             |
| -------- | -------------------------------- | ------------------------------------- |
| Frontend | `BACKEND_URL`                    | Riven's API, e.g. `http://riven:3000` |
| Frontend | `ORIGIN`                         | The URL you open the frontend at      |
| Riven    | `RIVEN_FRONTEND_SETTING__origin` | The same URL as `ORIGIN`              |
