title: Default

The default preset provides a balanced ranking configuration that prioritises higher-quality content.

## Usage

Select _Default_ under **Settings → Ranking**. It is the built-in profile Riven uses until you choose another one. Built-in profiles can be selected or duplicated, but not edited or deleted.
